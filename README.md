# 📄 Gerenciador de Ordens de Serviço

Sistema web completo, leve e moderno desenvolvido para gerenciamento eficiente de Ordens de Serviço (O.S.), controle de clientes, fluxo de caixa mensal e relatórios prontos para impressão.

---

## 🚀 Funcionalidades Principais

* **Emissão e Preview de O.S.:** Visualização imediata do documento formatado à medida que os campos são preenchidos.
* **Gestão de Clientes (CRUD):** Cadastro completo com preenchimento automático de endereço via API ViaCEP.
* **Controle Financeiro Mensal:** Acompanhamento dinâmico do faturamento do mês atual, valores recebidos e montantes pendentes.
* **Múltiplos Status de Pagamento:** Alternância rápida entre status de O.S. (`À Receber` e `Recebido / Pago`).
* **Relatório de Fechamento:** Extrato consolidado de valores em aberto por cliente para conferência rápida.
* **Modo Escuro (Dark Mode):** Alternância fluida entre temas claro e escuro.
* **Segurança de Dados:** Ferramenta integrada de exportação e importação de dados via arquivos `.json` para backup local.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5** & **JavaScript (ES6+)**
* **Tailwind CSS** (estilização responsiva via CDN)
* **Font Awesome** (ícones)
* **API ViaCEP** (integração de endereços)
* **LocalStorage** (persistência local de dados)

---

## 📦 Como Utilizar

1. Faça o download ou clone este repositório em sua máquina.
2. Abra o arquivo principal (`index.html`) em qualquer navegador web moderno (Google Chrome, Microsoft Edge, Firefox, etc.).
3. O sistema estará pronto para uso imediato, sem necessidade de instalações complexas de servidores!
